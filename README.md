# منظومة مكتب السفر والسياحة

منظومة ويب بلغة بايثون (Flask + SQLite)، فيها قسم للعملاء وقسم للإدارة. تبدأ فاضية بدون أي بيانات.

## التشغيل على جهازك
```
pip install -r requirements.txt
python app.py
```
افتح http://localhost:5000 وأول مرة راح يطلب منك بيانات المكتب وحساب المدير.

## الرفع على GitHub
ارفع كل الملفات (ما عدا مجلد data). الملف `.gitignore` يتجاهله تلقائيًا.

## النشر على الإنترنت
المنظومة تحتاج استضافة بايثون، وGitHub Pages لا يشغّلها. خيارات: Render أو Railway أو PythonAnywhere.
- أمر التشغيل: `gunicorn app:app`
- لازم تربط مساحة تخزين دائمة (Disk) وتحط مسارها في متغير `DATA_DIR`، لأن قاعدة البيانات والمستندات المرفوعة تنحفظ هناك. بدون تخزين دائم تضيع البيانات مع كل إعادة تشغيل.
- متغير `SECRET_KEY` اختياري (لو ما حطيته ينشأ تلقائيًا داخل DATA_DIR).

## التحديث من النسخة الأولى
استبدل الملفات فقط (app.py و templates و static) وخلّي مجلد data كما هو. المنظومة تحدّث قاعدة البيانات تلقائيًا بدون ما تخسر شي.

## ملاحظات
- لو النشر خلف HTTPS فعّل متغير `SECURE_COOKIES=1`.
- مفتاح الدولة لروابط واتساب يتغير من الإعدادات (الافتراضي 218).
- النسخ الاحتياطي: انسخ مجلد DATA_DIR بشكل دوري.
- الدخول برقم الهاتف وكلمة المرور.
